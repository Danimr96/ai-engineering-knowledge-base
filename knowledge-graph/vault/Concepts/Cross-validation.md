# Cross-validation

**Community:** [[Communities/04 Overfitting · Underfitting · Data Leakage|04 Overfitting · Underfitting · Data Leakage]]

> *What people say:* "Testing on different chunks"

**What it actually means:** Repeatedly splitting data into train/test folds and averaging results, giving a more robust performance estimate
