# Bagging

**Community:** [[Communities/04 Overfitting · Underfitting · Data Leakage|04 Overfitting · Underfitting · Data Leakage]]

> *What people say:* "Train on random subsets"

**What it actually means:** Bootstrap aggregating. Train each model on a different random sample with replacement
