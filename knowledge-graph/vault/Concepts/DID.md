# DID

**Community:** [[Communities/06 Communicative dehallucination · Consensus · Contract Net|06 Communicative dehallucination · Consensus · Contract Net]]

> *What people say:* "Decentralized ID"

**What it actually means:** W3C standard for cryptographically verifiable identities hosted on the agent's own domain. ANP uses did:wba method.
