# Shadow Mode

**Community:** [[Communities/41 Prompt Cache · Cache hit rate · Model routing|41 Prompt Cache · Cache hit rate · Model routing]]

> *What people say:* "Dark launch"

**What it actually means:** Running a new prompt or model on real traffic but only logging results, not showing them to users -- risk-free A/B testing
