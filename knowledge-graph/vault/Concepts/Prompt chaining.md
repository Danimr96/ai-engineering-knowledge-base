# Prompt chaining

**Community:** [[Communities/42 Few-Shot · Prompt Engineering · In-Context Learning|42 Few-Shot · Prompt Engineering · In-Context Learning]]

> *What people say:* "Break it into steps"

**What it actually means:** Decomposing a complex task into sequential prompts where each output feeds the next input
