# Binary cross-entropy

**Community:** [[Communities/04 Overfitting · Underfitting · Data Leakage|04 Overfitting · Underfitting · Data Leakage]]

> *What people say:* "Log loss"

**What it actually means:** The loss function -[ylog(p) + (1-y)log(1-p)] that penalizes confident wrong predictions severely
