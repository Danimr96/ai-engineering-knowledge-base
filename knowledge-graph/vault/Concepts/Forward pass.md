# Forward pass

**Community:** [[Communities/22 Backward pass · Forward pass · Vanishing gradient|22 Backward pass · Forward pass · Vanishing gradient]]

> *What people say:* "Running the model"

**What it actually means:** Pushing input through every layer -- multiply by weights, add bias, activate -- to produce an output
