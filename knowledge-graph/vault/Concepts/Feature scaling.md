# Feature scaling

**Community:** [[Communities/04 Overfitting · Underfitting · Data Leakage|04 Overfitting · Underfitting · Data Leakage]]

> *What people say:* "Make features comparable"

**What it actually means:** Transforming features to similar ranges (e.g., zero mean, unit variance) so gradient descent converges faster
