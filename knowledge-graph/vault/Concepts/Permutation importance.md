# Permutation importance

**Community:** [[Communities/04 Overfitting · Underfitting · Data Leakage|04 Overfitting · Underfitting · Data Leakage]]

> *What people say:* "Shuffle and check"

**What it actually means:** Accuracy drop when a feature's values are randomly shuffled. More reliable than MDI for noisy features
