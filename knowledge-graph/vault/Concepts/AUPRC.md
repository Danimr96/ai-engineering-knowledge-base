# AUPRC

**Community:** [[Communities/04 Overfitting · Underfitting · Data Leakage|04 Overfitting · Underfitting · Data Leakage]]

> *What people say:* "Area under precision-recall curve"

**What it actually means:** A metric that summarizes precision-recall performance across all thresholds, better than AUROC for imbalanced data

*Not in the glossary: this concept exists because lessons list it in their Key Terms table. If it is really a glossary term under another name, add it to `data/aliases.json`.*
