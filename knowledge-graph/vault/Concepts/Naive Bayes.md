# Naive Bayes

**Community:** [[Communities/04 Overfitting · Underfitting · Data Leakage|04 Overfitting · Underfitting · Data Leakage]]

> *What people say:* "That simple text classifier"

**What it actually means:** A classifier that assumes features are independent given the class. Works well despite the false assumption.
