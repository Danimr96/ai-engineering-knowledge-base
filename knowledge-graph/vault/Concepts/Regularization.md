# Regularization

**Community:** [[Communities/04 Overfitting · Underfitting · Data Leakage|04 Overfitting · Underfitting · Data Leakage]]

> *What people say:* "Keeping weights small"

**What it actually means:** Adding a penalty term to the loss function that discourages overly complex models
