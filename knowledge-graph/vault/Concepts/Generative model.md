# Generative model

**Community:** [[Communities/88 FID · Generative model|88 FID · Generative model]]

> *What people say:* "Models how data is generated"

**What it actually means:** A model that learns P(X | Y) and P(Y), then uses Bayes' theorem to get P(Y | X)
