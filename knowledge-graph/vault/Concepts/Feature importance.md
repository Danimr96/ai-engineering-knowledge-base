# Feature importance

**Community:** [[Communities/04 Overfitting · Underfitting · Data Leakage|04 Overfitting · Underfitting · Data Leakage]]

> *What people say:* "Which features matter"

**What it actually means:** Total impurity decrease contributed by each feature, summed across all trees and nodes
