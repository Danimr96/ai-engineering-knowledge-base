# Convex function

> *What people say:* "One valley"

**What it actually means:** A function where any local minimum is the global minimum. Gradient descent always finds it. Neural network losses are not convex.

*Not in the glossary: this concept exists because lessons list it in their Key Terms table. If it is really a glossary term under another name, add it to `data/aliases.json`.*
