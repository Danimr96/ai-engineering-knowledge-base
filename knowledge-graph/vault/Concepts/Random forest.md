# Random forest

**Community:** [[Communities/04 Overfitting · Underfitting · Data Leakage|04 Overfitting · Underfitting · Data Leakage]]

> *What people say:* "A bunch of trees"

**What it actually means:** Ensemble of decision trees, each trained on a bootstrap sample with random feature subsets at each split
