## Concepts taught

- LSP `lesson term` — Language Server Protocol: a standard for editors to get type info, completions, and diagnostics from a language-specific server
- Pylance `lesson term` — Microsoft's Python language server using Pyright for type checking and IntelliSense
- Remote SSH `lesson term` — VS Code extension that runs a lightweight server on a remote machine and streams the UI to your local editor
- Format on save `lesson term` — The editor runs a formatter (Black, Ruff) every time you save, so code style is always consistent
