## Concepts taught

- Shell `lesson term` — The program that interprets your commands (bash, zsh, fish)
- tmux `lesson term` — A program that lets you run multiple terminal sessions inside one window, and detach/reattach
- Pipe `lesson term` — The | operator that sends one command's output as input to another
- PID `lesson term` — A unique number assigned to every running process, used to monitor or kill it
- nohup `lesson term` — Runs a command immune to the hangup signal, so closing the terminal won't kill it
- SSH `lesson term` — Secure Shell, an encrypted protocol for running commands on a remote machine
